# EngCalcs commercial licence transition

Current status (2026-10-11): the UI is proprietary under ../LICENSE, while
EngCalcs, EngCalcs-Wind and five AS modules still declare AGPL-3.0-only.
Changing this UI notice does not change those independently licensed packages.

Previously granted AGPL rights remain effective for historical versions.
Prospective relicensing requires verified ownership of all incorporated code,
including contributed work, and preservation of required third-party notices.
In particular, the AS 4100 module retains the steel-as MIT attribution.
Other third-party dependencies and licensed standards/data require review.

**Pending operational steps:**
1. Make all eight GitHub repositories private through an administrator;

2. Confirm chain of title and licence compatibility for incorporated code.
3. Coordinate future-version backend/module licence files, SPDX headers,
   package metadata, REST/MCP provenance and deployment configuration.

Do not claim the backend is proprietary before a lawful change is complete.
This is a technical distribution checklist, not a legal opinion.
